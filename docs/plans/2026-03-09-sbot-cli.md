# sbot CLI 与进程管理 实现计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将 ScapegoatBot 从单一 main() 改造为完整的 CLI 工具 `sbot`，支持 start/stop/restart、AI Agent 开关控制、chat 自然语言指令，通过本地 TCP 控制通道实现进程间通信。

**Architecture:** 二进制名 `sbot`，使用 `clap` derive 模式解析命令行。`sbot start` 启动守护进程（前台/后台），守护进程在 localhost TCP 端口监听控制命令。后续 CLI 调用（stop/ai/chat/status）作为客户端连接控制端口发送 JSON 指令并等待响应。AI Agent 状态用 `AtomicBool` 控制开关，stop 时消息收集/存储/风格解析继续，仅暂停 LLM 调用。

**Tech Stack:** clap 4（CLI 解析），tokio TCP（控制通道），serde_json（控制协议），daemonize（后台模式，仅 Unix；Windows 用 detached process spawn）。

```rust
// src/control.rs
// 控制通道协议定义
// 守护进程在 localhost TCP 端口监听，CLI 客户端发送 ControlRequest，接收 ControlResponse

use serde::{Deserialize, Serialize};

/// 默认控制端口
pub const DEFAULT_CONTROL_PORT: u16 = 19800;

/// 控制请求（CLI → 守护进程）
#[derive(Debug, Serialize, Deserialize)]
#[serde(tag = "type")]
pub enum ControlRequest {
    /// 请求关闭守护进程
    Shutdown,
    /// 查询运行状态
    Status,
    /// 控制 AI Agent
    Ai { action: AiControlAction },
    /// 发送自然语言 Chat 指令
    Chat {
        message: String,
        /// 本轮限定群白名单（空=不限定，使用全局）
        group_filter: Vec<i64>,
        /// 本轮限定私聊白名单（空=不限定，使用全局）
        private_filter: Vec<i64>,
    },
}

/// AI Agent 控制动作
#[derive(Debug, Serialize, Deserialize)]
pub enum AiControlAction {
    Start,
    Stop,
    Restart,
}

/// 控制响应（守护进程 → CLI）
#[derive(Debug, Serialize, Deserialize)]
pub struct ControlResponse {
    /// 是否成功
    pub ok: bool,
    /// 消息（成功时为状态信息，失败时为错误描述）
    pub message: String,
}

impl ControlResponse {
    pub fn ok(msg: impl Into<String>) -> Self {
        Self { ok: true, message: msg.into() }
    }
    pub fn err(msg: impl Into<String>) -> Self {
        Self { ok: false, message: msg.into() }
    }
}
```

**Step 2: 添加 TCP 收发辅助函数**

协议格式：`4 字节大端长度 + JSON payload`。

```rust
use tokio::io::{AsyncReadExt, AsyncWriteExt};
use tokio::net::TcpStream;

/// 发送一条 JSON 消息（长度前缀帧）
pub async fn send_msg<T: Serialize>(stream: &mut TcpStream, msg: &T) -> anyhow::Result<()> {
    let json = serde_json::to_vec(msg)?;
    let len = (json.len() as u32).to_be_bytes();
    stream.write_all(&len).await?;
    stream.write_all(&json).await?;
    Ok(())
}

/// 接收一条 JSON 消息（长度前缀帧）
pub async fn recv_msg<T: serde::de::DeserializeOwned>(stream: &mut TcpStream) -> anyhow::Result<T> {
    let mut len_buf = [0u8; 4];
    stream.read_exact(&mut len_buf).await?;
    let len = u32::from_be_bytes(len_buf) as usize;
    // 防止恶意超大负载
    anyhow::ensure!(len <= 1_048_576, "控制消息过大: {len} bytes");
    let mut buf = vec![0u8; len];
    stream.read_exact(&mut buf).await?;
    Ok(serde_json::from_slice(&buf)?)
}
```

```rust
// src/agent_state.rs
// AI Agent 运行状态
// 使用 AtomicBool 控制 AI 是否活跃
// stop 时消息收集/存储/风格解析继续，仅暂停 LLM 调用

use std::sync::atomic::{AtomicBool, Ordering};

/// AI Agent 全局运行状态
#[derive(Debug)]
pub struct AgentState {
    /// AI Agent 是否活跃（true = 运行中，false = 已暂停）
    active: AtomicBool,
}

impl AgentState {
    /// 创建新状态（默认活跃）
    pub fn new(active: bool) -> Self {
        Self { active: AtomicBool::new(active) }
    }

    /// AI Agent 是否活跃
    pub fn is_active(&self) -> bool {
        self.active.load(Ordering::Relaxed)
    }

    /// 启动 AI Agent
    pub fn activate(&self) {
        self.active.store(true, Ordering::Relaxed);
    }

    /// 暂停 AI Agent
    pub fn deactivate(&self) {
        self.active.store(false, Ordering::Relaxed);
    }
}
```

**Step 1: 实现控制服务端**

守护进程启动时调用 `start_control_server()`，在后台监听 TCP 连接、处理请求。

```rust
// src/control_server.rs
// 控制通道服务端
// 守护进程在 localhost:port 监听来自 CLI 的控制指令

use crate::agent_state::AgentState;
use crate::control::*;
use std::sync::Arc;
use tokio::net::TcpListener;
use tokio::sync::broadcast;

/// 控制服务端上下文
pub struct ControlServer {
    /// AI Agent 状态
    pub agent_state: Arc<AgentState>,
    /// 关闭信号发送端
    pub shutdown_tx: broadcast::Sender<()>,
}

/// 启动控制服务端（在后台 tokio 任务中运行）
pub async fn start_control_server(
    port: u16,
    ctx: Arc<ControlServer>,
) -> anyhow::Result<()> {
    let listener = TcpListener::bind(format!("127.0.0.1:{port}")).await?;
    tracing::info!("控制通道已监听: 127.0.0.1:{port}");

    loop {
        let (mut stream, addr) = listener.accept().await?;
        let ctx = ctx.clone();
        tokio::spawn(async move {
            if let Err(e) = handle_control_connection(&mut stream, &ctx).await {
                tracing::warn!("控制连接 {addr} 处理失败: {e}");
            }
        });
    }
}

async fn handle_control_connection(
    stream: &mut tokio::net::TcpStream,
    ctx: &ControlServer,
) -> anyhow::Result<()> {
    let req: ControlRequest = recv_msg(stream).await?;
    let resp = match req {
        ControlRequest::Shutdown => {
            tracing::info!("收到关闭指令");
            let _ = ctx.shutdown_tx.send(());
            ControlResponse::ok("正在关闭...")
        }
        ControlRequest::Status => {
            let ai_status = if ctx.agent_state.is_active() { "运行中" } else { "已暂停" };
            ControlResponse::ok(format!("sbot 运行中 | AI Agent: {ai_status}"))
        }
        ControlRequest::Ai { action } => handle_ai_action(&ctx.agent_state, action),
        ControlRequest::Chat { message, group_filter, private_filter } => {
            // TODO: Task 8 中实现，当前返回占位
            let _ = (message, group_filter, private_filter);
            ControlResponse::ok("chat 功能尚未实现")
        }
    };
    send_msg(stream, &resp).await?;
    Ok(())
}

/// 处理 AI Agent 控制命令
fn handle_ai_action(state: &AgentState, action: AiControlAction) -> ControlResponse {
    match action {
        AiControlAction::Start => {
            if state.is_active() {
                ControlResponse::ok("AI Agent 已经在运行中")
            } else {
                state.activate();
                tracing::info!("AI Agent 已启动");
                // TODO: 触发启动初始化检查（Task 9）
                ControlResponse::ok("AI Agent 已启动")
            }
        }
        AiControlAction::Stop => {
            if !state.is_active() {
                ControlResponse::ok("AI Agent 已经处于暂停状态")
            } else {
                state.deactivate();
                tracing::info!("AI Agent 已暂停（消息收集继续）");
                ControlResponse::ok("AI Agent 已暂停（消息收集继续）")
            }
        }
        AiControlAction::Restart => {
            state.deactivate();
            state.activate();
            tracing::info!("AI Agent 已重启");
            // TODO: 触发启动初始化检查（Task 9）
            ControlResponse::ok("AI Agent 已重启")
        }
    }
}
```

```rust
use clap::Parser;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let cli = cli::Cli::parse();

    match cli.command {
        // 无子命令或 start → 启动守护进程
        None | Some(cli::Commands::Start { .. }) => {
            let daemon = matches!(&cli.command, Some(cli::Commands::Start { daemon: true, .. }));
            if daemon {
                // 后台模式：spawn detached 子进程后退出
                spawn_daemon(&cli.config)?;
            } else {
                // 前台模式：直接运行
                run_daemon(&cli.config).await?;
            }
        }
        Some(cli::Commands::Restart { daemon }) => {
            // 先尝试发送 shutdown，忽略连接失败（可能未运行）
            let _ = send_control(&cli.config, ControlRequest::Shutdown).await;
            tokio::time::sleep(std::time::Duration::from_millis(500)).await;
            if daemon {
                spawn_daemon(&cli.config)?;
            } else {
                run_daemon(&cli.config).await?;
            }
        }
        Some(cli::Commands::Stop) => {
            let resp = send_control(&cli.config, ControlRequest::Shutdown).await?;
            println!("{}", resp.message);
        }
        Some(cli::Commands::Status) => {
            let resp = send_control(&cli.config, ControlRequest::Status).await?;
            println!("{}", resp.message);
        }
        Some(cli::Commands::Ai { action }) => {
            let ctrl_action = match action {
                cli::AiAction::Start => AiControlAction::Start,
                cli::AiAction::Stop => AiControlAction::Stop,
                cli::AiAction::Restart => AiControlAction::Restart,
            };
            let resp = send_control(&cli.config, ControlRequest::Ai { action: ctrl_action }).await?;
            println!("{}", resp.message);
        }
        Some(cli::Commands::Chat { message, group, private }) => {
            let resp = send_control(&cli.config, ControlRequest::Chat {
                message,
                group_filter: group,
                private_filter: private,
            }).await?;
            println!("{}", resp.message);
        }
    }
    Ok(())
}
```

```rust
async fn run_daemon(config_path: &str) -> anyhow::Result<()> {
    // 初始化 tracing
    tracing_subscriber::fmt()
        .with_env_filter(
            tracing_subscriber::EnvFilter::try_from_default_env()
                .unwrap_or_else(|_| tracing_subscriber::EnvFilter::new("info")),
        )
        .init();

    tracing::info!("ScapegoatBot 启动中...");

    let config = AppConfig::load(Path::new(config_path))?;
    // ... 原有的初始化逻辑（白名单、存储、Skill、NapCat 连接）...

    // === 新增：AI Agent 状态 + 控制通道 ===
    let agent_state = Arc::new(AgentState::new(true));
    let (shutdown_tx, mut shutdown_rx) = tokio::sync::broadcast::channel::<()>(1);

    let ctrl_server = Arc::new(ControlServer {
        agent_state: agent_state.clone(),
        shutdown_tx: shutdown_tx.clone(),
    });
    tokio::spawn(start_control_server(config.control.port, ctrl_server));

    // ... 原有的消息监听 tokio::spawn ...

    // 连接 NapCat
    client.connect().await?;
    tracing::info!("已连接到 NapCat: {}", config.napcat.ws_url);

    // 等待关闭信号
    tokio::select! {
        _ = tokio::signal::ctrl_c() => {
            tracing::info!("收到 Ctrl+C 信号");
        }
        _ = shutdown_rx.recv() => {
            tracing::info!("收到远程关闭指令");
        }
    }
    tracing::info!("正在断开连接...");
    client.disconnect();
    Ok(())
}
```

**Step 4: 实现 spawn_daemon() — 后台模式**

```rust
/// 以后台模式启动：spawn 一个 detached 子进程运行 `sbot start`（不带 -d）
fn spawn_daemon(config_path: &str) -> anyhow::Result<()> {
    let exe = std::env::current_exe()?;
    let mut cmd = std::process::Command::new(exe);
    cmd.args(["start", "-c", config_path]);

    // 平台相关 detach 设置
    #[cfg(windows)]
    {
        use std::os::windows::process::CommandExt;
        // CREATE_NEW_PROCESS_GROUP | DETACHED_PROCESS
        cmd.creation_flags(0x00000010 | 0x00000008);
    }
    #[cfg(unix)]
    {
        use std::os::unix::process::CommandExt;
        unsafe { cmd.pre_exec(|| { libc::setsid(); Ok(()) }); }
    }

    cmd.stdin(std::process::Stdio::null())
        .stdout(std::process::Stdio::null())
        .stderr(std::process::Stdio::null());

    let child = cmd.spawn()?;
    println!("sbot 已在后台启动 (PID: {})", child.id());
    Ok(())
}
```
